# Xá das Cinco - Landing Page

Agência de Comunicação Estratégica, Branding e Marketing Criativo para mercados de beleza, moda e lifestyle de alto padrão.

## 🛠️ Tech Stack

- **React 18** - UI Framework
- **Vite** - Build tool
- **Tailwind CSS 3** - Utility-first CSS
- **Playfair Display & Lato** - Brand Typography

## 📦 Instalação & Setup

```bash
# Instalar dependências
npm install

# Rodar desenvolvimento
npm run dev

# Build para produção
npm run build

# Preview da build
npm run preview
```

## 📐 Estrutura de Componentes

- **Navigation** - Logo e links principais
- **Hero Section** - Headline com CTA principal
- **Services** - 3 Expertises principais
- **Methodology** - 4 etapas do processo
- **Portfolio** - Cases com filtros (Beleza, Moda, Personal Branding)
- **Project Briefing** - Form elegante para consulta
- **FAQ** - Perguntas frequentes
- **Contact Section** - Informações de contato
- **Footer** - Navegação secundária e social

## 🚀 Deploy

O projeto está pronto para deploy em:

- AWS Amplify

Basta executar `npm run build` e fazer upload da pasta `dist/`.
